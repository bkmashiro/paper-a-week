# 009 — GAN：生成对抗网络

**论文：** Ian J. Goodfellow 等，2014 | **会议：** NeurIPS 2014  
**链接：** https://arxiv.org/abs/1406.2661

---

## 背景

在 GAN 出现之前，生成模型的主流方案要么计算代价极高，要么依赖强假设。受限玻尔兹曼机（RBM）和深度玻尔兹曼机在训练时需要马尔可夫链蒙特卡洛采样，收敛慢、计算贵。变分自编码器（VAE）虽然绕过了这一问题，但它在输出空间假设高斯分布，生成的图像往往模糊。归根结底，这些方法都需要在像素空间上定义并优化一个显式的概率密度函数——这本身就是一个很难写好的目标。

Goodfellow 等人彻底换了一种思路：既然密度难以定义，能不能用另一个神经网络来"学习"什么样的样本是真实的？这就是 GAN 的核心思想——博弈论框架。生成器（Generator）尝试生成以假乱真的样本，判别器（Discriminator）则努力辨别真伪。整个训练过程不需要任何显式密度函数，学习信号完全来自对抗博弈。

这个想法影响深远。把一个神经网络当作另一个网络的损失函数，打开了条件图像生成（pix2pix）、风格迁移、超分辨率（SRGAN）等一系列应用的大门，并深刻影响了后来的扩散模型。GAN 开创了视觉生成 AI 的一整个时代。

---

## 核心思想

### 极小极大博弈

GAN 的训练目标是一个二人极小极大博弈：

```
min_G  max_D  V(D, G)  =  E_{x ~ p_data}[log D(x)]  +  E_{z ~ p_z}[log(1 - D(G(z)))]
```

- **D(x)**：x 是真实样本的概率（输出范围 (0,1)）
- **G(z)**：从噪声 z ~ p_z(z)（通常 z ~ N(0, I)）生成的样本
- **D 的目标**：把真样本判为真（log D(x) 趋近 0），把假样本判为假（log(1 − D(G(z))) 趋近 0）
- **G 的目标**：让 D 把假样本误判为真（log(1 − D(G(z))) 趋近 −∞）

理论上，当博弈达到纳什均衡时，G 完美复现了真实数据分布 p_data，此时 D(x) ≡ 1/2——判别器已无法区分真假。

### 最优判别器与 JSD

对于固定的 G，最优判别器是：

```
D*_G(x) = p_data(x) / (p_data(x) + p_g(x))
```

将最优判别器代入价值函数，可以得到生成器实际在最小化的目标：

```
C(G) = -log(4) + 2 · JSD(p_data || p_g)
```

其中 JSD 是 Jensen-Shannon 散度，非负且有界。当 p_g = p_data 时，JSD = 0，C(G) 取最小值 -log(4)。这从理论上证明了 GAN 的全局最优解确实是让生成分布匹配真实分布。

### 训练算法

训练采用交替梯度下降：

```
每个训练步骤：
  1. 从真实数据采样 m 个样本 {x_1, ..., x_m}
  2. 从噪声分布采样 m 个噪声向量 {z_1, ..., z_m}
  3. 更新判别器 D（梯度上升）：
       ∇_θd  (1/m) Σ [log D(x_i) + log(1 − D(G(z_i)))]
  4. 重新采样 m 个噪声向量
  5. 更新生成器 G（梯度下降）：
       ∇_θg  (1/m) Σ log(1 − D(G(z_i)))
     [实践中改为上升 ∇_θg  (1/m) Σ log D(G(z_i))——非饱和技巧]
```

### 非饱和生成器损失

原论文 G 的目标 `log(1 − D(G(z)))` 在训练初期存在梯度消失问题：当判别器轻松识破假样本时，该项饱和，梯度几乎为零。实践中普遍改用等价的非饱和形式：

```
# 原论文（理论分析用）：
loss_G = log(1 - D(G(z)))   # 训练初期梯度极弱

# 实践默认（相同纳什均衡）：
loss_G = -log(D(G(z)))      # 全程梯度充足
```

这是一个既不改变理论收敛点、又极大改善训练稳定性的工程技巧。

## 实现说明

### 保留了什么

- 完整的极小极大博弈：生成器 + 判别器两个 MLP
- 非饱和生成器损失（实际工程写法）
- 交替梯度下降（每步 1 次 D 更新 + 1 次 G 更新）
- 二元交叉熵损失函数
- 完整的训练循环与指标追踪

### 简化了什么

- 目标分布：用 1D 高斯混合分布代替图像数据，CPU 即可秒跑
- 使用小型 MLP，而非深度 CNN
- 省略了学习率调度、谱归一化等高级技巧
- 没有批归一化（BN 是 DCGAN 2015 引入的）

### 关键代码要点

**`.detach()` 的重要性**：计算判别器损失时，需要对 `D(G(z))` 中的 `G(z)` 进行 `.detach()`，防止梯度回流到 G 的参数——判别器优化器只应更新 D。

**KL 散度评估**：演示结尾用直方图估计真实分布和生成分布之间的 KL 散度，量化 G 是否真正学到了目标分布。

## 核心收获

1. **无需显式密度**：GAN 彻底绕开了难以定义的像素空间密度函数，改用对抗反馈作为学习信号。

2. **对抗信号是强力的课程**：对抗训练会自动把生成器"引导"到判别器最容易识破的弱点上——本质是一种自适应难例挖掘。

3. **训练不稳定是固有特性**：模式崩溃（G 只生成少数几种样本）、判别器饱和、损失震荡，这些问题在原始 GAN 中天然存在。WGAN（Wasserstein GAN）、谱归一化、梯度惩罚等后续工作都是针对这些问题的系统性修复。

4. **非饱和技巧要记住**：理论分析 `log(1 - D(G(z)))`，工程实践 `-log(D(G(z)))`，二者等价但梯度性质天差地别。

5. **GAN 属于隐式生成模型**：GAN 不定义 p_g 的解析形式，只提供采样过程。这一类模型（包括后来的扩散模型）在高质量图像生成上碾压了 VAE 的显式密度方法。
