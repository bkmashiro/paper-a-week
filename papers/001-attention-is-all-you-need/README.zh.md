# 001 — Attention Is All You Need（注意力机制就是你所需要的一切）

[English](README.md)

**论文：** Vaswani et al., 2017 | **发表于：** NeurIPS 2017  
**链接：** https://arxiv.org/abs/1706.03762

---

## 背景

2017 年之前，序列到序列（seq2seq）模型几乎清一色依赖循环神经网络（RNN、LSTM、GRU）。这类模型有两个根本性缺陷：

1. **串行计算**：token 必须一个接一个地处理，无法在时间步上并行，训练速度极慢。
2. **长程梯度消失**：序列越长，早期 token 的梯度越难传播到后期，模型对"远古"上下文的记忆能力很弱。

注意力机制（Attention）当时已经存在，但只是 RNN 的一个附件——编码器-解码器框架中让解码器"回望"编码器状态的小技巧。

Vaswani 等人的提案是颠覆性的：**完全抛弃循环结构，整个模型只用注意力来建模序列关系。** 这就是 Transformer。

结果非常惊艳：

- 训练速度大幅提升（序列长度维度完全并行）
- 长程依赖捕捉能力更强（任意两个位置的注意力路径为 O(1)，不存在梯度消失）
- 成为此后所有主流语言模型的基础架构——GPT、BERT、T5 以及它们所有的后代，都是 Transformer。

Transformer 的主体是一个**编码器-解码器**结构，编码器和解码器均由若干个相同的层叠加而成，每层包含一个多头自注意力子层和一个前馈网络子层。

## 核心思想

### 1. 缩放点积注意力（Scaled Dot-Product Attention）

给定查询矩阵 Q、键矩阵 K 和值矩阵 V，注意力的计算公式为：

```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
```

逐步拆解：

- **Q · Kᵀ**：计算每个查询与所有键之间的相似度得分（点积），得到一个 seq×seq 的分数矩阵。
- **/ √d_k**：除以维度的平方根进行缩放。当 d_k 较大时，点积值也会很大，导致 softmax 输出极度尖锐（梯度消失）。除以 √d_k 可以稳定训练。
- **softmax**：将原始分数转换为概率分布，每行和为 1，代表"这个 token 应该多关注哪些其他 token"。
- **· V**：用注意力权重对值向量做加权求和，得到每个查询的"答案"。

直观理解：Q 是"我想找什么"，K 是"我是什么"，V 是"我能提供什么"。注意力让每个 token 去找与自己最相关的其他 token，并聚合它们的信息。

### 2. 多头注意力（Multi-Head Attention）

单次注意力只能让模型从一个"视角"看序列。为了让模型同时从多个视角捕捉信息（例如：句法关系、语义相似性、指代关系），论文引入了多头注意力：

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W_O
其中 head_i = Attention(Q W_Qi, K W_Ki, V W_Vi)
```

关键点：
- 总共有 h 个头，每个头有自己的投影矩阵 W_Qi、W_Ki、W_Vi。
- 每个头的维度 d_k = d_model / h，所以总计算量与单头相同，不会增加额外开销。
- 所有头的输出拼接后，再经过一个 W_O 投影矩阵输出。

不同的头会自然学到不同类型的注意力模式——有的头关注局部依赖，有的头关注全局语义，这是多头的精妙之处。

### 3. 位置编码（Positional Encoding）

注意力机制本身对位置没有感知——无论 token 顺序如何打乱，softmax(QKᵀ)V 的结果集合是相同的（只是排列不同）。为了注入位置信息，论文在输入嵌入上加入位置编码：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

用正弦/余弦函数，每个位置对应一个唯一的编码向量，且相对位置可以通过线性变换表示——这使得模型能够泛化到训练时未见过的序列长度。

### 4. 前馈网络（Feed-Forward Network）

每层注意力子层之后跟一个位置相关的前馈网络（对每个 token 独立、相同地应用）：

```
FFN(x) = max(0, x W_1 + b_1) W_2 + b_2
```

内层维度通常是模型维度的 4 倍（如 d_model=512，则 FFN 内层为 2048）。FFN 提供了注意力之外的"非线性变换"能力，被认为是模型存储知识的重要部分。

### 5. 残差连接与层归一化

每个子层（注意力或 FFN）都用残差连接包裹：

```
输出 = LayerNorm(x + Sublayer(x))
```

残差连接解决了深层网络梯度消失的问题，使梯度能够直接流过网络深处；层归一化则稳定了训练过程中的激活值分布。

## 实现解析

### 保留了什么

本周实现包含了以下核心部分：

- 精确的缩放点积注意力公式
- 多头注意力（含各头独立的投影矩阵）
- 前馈网络（内层维度 = 4 × d_model）
- 残差连接 + 层归一化
- 完整的 `TransformerBlock` = 注意力 + FFN + 归一化

### 简化了什么

- **不含位置编码**：专注于注意力机制本身；添加正弦位置编码很简单但会分散注意力
- **仅编码器**：没有交叉注意力解码器（否则代码量翻倍）
- **仅用 numpy**：无自动求导，仅前向传播，权重随机初始化（演示形状）
- **无 masking**：省略了因果 mask 和 padding mask

### 核心代码解读

**缩放点积注意力**（约第 30–50 行）：

```python
scores = Q @ K.T / math.sqrt(d_k)   # (seq, seq) 相似度矩阵
weights = softmax(scores)             # 注意力分布
return weights @ V                    # 加权求和
```

**多头注意力**（约第 55–90 行）：将 d_model 分成 h 个头，对每个头独立做注意力，再拼接：

```python
head_out = attention(Q @ Wq, K @ Wk, V @ Wv)   # (seq, d_k)
# 所有头拼接后：concat → (seq, d_model) → 再用 W_O 投影
```

**TransformerBlock**（约第 110–145 行）：多头注意力 + FFN，每个都包在残差 + 层归一化里。

## 关键收获

### 1. Transformer 为什么能取代 RNN？

| 维度 | RNN/LSTM | Transformer |
|------|----------|-------------|
| 并行度 | 串行（时间步依赖） | 完全并行（序列长度维度） |
| 长程依赖 | 路径长度 O(N)，梯度消失 | 路径长度 O(1)，直接关注 |
| 内存 | O(N)（仅需保存隐状态） | O(N²)（注意力矩阵） |
| 可解释性 | 较难 | 可视化注意力权重 |

Transformer 的代价是内存和计算随序列长度平方增长——这正是 FlashAttention（第 003 篇）要解决的问题。

### 2. Multi-Head 的直觉

可以把多头注意力想象成"多个专家委员会"同时审查序列的不同方面，再把结论汇总。每个头专注于不同的语言现象，使模型的表达能力远超单头。

### 3. 为什么 d_k 的缩放这么重要？

假设 Q 和 K 的每个元素都独立服从均值为 0、方差为 1 的正态分布。那么 Q·K 中每个元素是 d_k 个乘积之和，其方差为 d_k。当 d_k=512 时，标准差高达约 22——这会使 softmax 输入非常大，梯度接近 0。除以 √d_k 把方差拉回到 1，梯度才能正常流动。

### 4. 历史影响

这篇论文是 NLP（乃至整个深度学习）近十年最重要的论文之一。它直接催生了：

- **BERT**（2018）：仅用编码器，双向注意力，预训练语言模型
- **GPT 系列**（2018–至今）：仅用解码器，自回归生成
- **T5**（2019）：编码器-解码器，统一的文本到文本范式
- **Vision Transformer (ViT)**（2020）：把图像切成 patch 当 token 用
- **Stable Diffusion 的 U-Net**：扩散模型中的交叉注意力

可以说，没有 Transformer，就没有 ChatGPT。
