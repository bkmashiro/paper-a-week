# 010 — Word2Vec：词语的分布式表示

**论文：** Mikolov, T., Sutskever, I., Chen, K., Corrado, G., Dean, J. (2013)  
**发表于：** NeurIPS 2013  
**链接：** https://arxiv.org/abs/1310.4546

---

## 背景：为什么需要词向量？

在 Word2Vec 出现之前，NLP 领域最常用的词表示方法是**独热编码（one-hot）**：用一个长度等于词表大小的稀疏向量来表示一个词，只有该词对应的位置是 1，其余全是 0。这种表示方式有两个致命缺陷：一是维度极高（词表动辄十万量级）；二是完全无法捕捉语义信息——"猫"和"小猫"之间的距离，与"猫"和"飞机"之间的距离是完全一样的。

用稠密向量来表示词义的想法其实由来已久，Bengio 等人在 2003 年就用神经网络语言模型来学习词向量。但问题在于效率：当时的方案需要对整个词表做 softmax，计算量随词表大小线性增长，在十亿规模的语料上训练基本不可行。

Mikolov 团队的创新在于两点：一是把复杂的神经网络语言模型**极度简化**，去掉非线性隐层；二是用**近似目标函数**替代精确 softmax。最终的结果令人惊讶：更简单的模型、更快的训练，反而得到了质量更高的词向量。2013 年的第二篇论文（"Distributed Representations of Words and Phrases"）进一步引入了负采样（Negative Sampling）和高频词下采样，把这套方法推向了工程实用。

---

## 核心思想

### 1. Skip-gram：用中心词预测上下文

Skip-gram 的训练目标很直观：给定句子中的一个词（中心词），预测它周围窗口内的其他词（上下文词）。

比如句子 "the cat sat on the mat"，窗口大小为 2 时，"sat" 这个词对应的训练样本是：
- (sat → the), (sat → cat), (sat → on), (sat → the)

模型从这些(中心词, 上下文词)对中学习：使真实出现的词对在向量空间中更接近，使随机抽取的"噪声词"对更远离。

与之对应的 CBOW 模型方向相反——用上下文预测中心词。实践中 Skip-gram 对低频词的效果更好，因为每个罕见词都会产生多个训练样本，反复强化其表示。

### 2. 负采样：用二分类替代多分类

原版 softmax 的问题在于每次更新都要遍历整个词表。负采样（Negative Sampling）的做法是把多分类问题转化为一系列**二分类问题**：

对于每一对 (中心词 w_I，上下文词 w_O)，训练目标变成：

```
最大化：log σ(v'_{w_O} · v_{w_I})           （真实上下文词得分高）
      + Σ_k log σ(−v'_{w_k} · v_{w_I})     （噪声词得分低）
```

其中 σ 是 sigmoid 函数，k 个噪声词从一个近似分布中随机采样。每次梯度更新只需要计算 K+1 个词（K 通常取 5~20），而不是整个词表。

**噪声分布的选取也有讲究。** 论文发现，用词频的 3/4 次方作为采样概率效果最好：

```
P_n(w) ∝ f(w)^{3/4}
```

这样做是为了"平滑"分布：纯词频采样会导致"的""是""在"这类高频虚词永远占据负样本；3/4 次方让低频词有更多机会被采样为负例，从而也能学到较好的向量表示。

### 3. 高频词下采样

训练语料中大量充斥着"the""a""of"这类对语义贡献极小的高频词。论文引入了随机丢弃机制：每个词以如下概率被跳过：

```
P(丢弃 w) = 1 − sqrt(t / f(w))
```

其中 f(w) 是词频，t 通常取 10⁻⁵。频率越高的词被丢弃的概率越大。这样做一方面加快了训练速度（丢弃了大量噪声 token），另一方面让有意义的低频词之间的共现信号更加突出，实际上提升了词向量质量。

### 4. 词向量空间的几何结构

Word2Vec 最令人惊喜的性质是词向量之间的线性代数关系：

```
v(king) − v(man) + v(woman) ≈ v(queen)
```

类比关系、国家-首都关系、形容词-比较级关系……都可以通过向量加减来表达。这个性质并不是人为设计的，而是从训练目标中**自然涌现**出来的：如果模型学会了把语义相似的词放在相近的位置，那么那些共享相同语义偏移的词对（如 man/woman, king/queen）自然会在向量空间中形成平行的几何结构。

## 实现要点

我们的实现包含 Skip-gram + 负采样的完整训练流程：

```
词汇表构建 → 词频统计 → 高频词下采样 → 构造噪声分布
→ 生成 (中心词, 上下文词) 训练对
→ 每个 pair：负采样 K 个噪声词，计算梯度，更新两个 embedding 矩阵
→ 训练完成后：用余弦相似度做最近邻检索、词类比计算
```

模型维护**两个 embedding 矩阵**：
- `W`（输入矩阵）：中心词 embedding，推理时使用
- `W'`（输出矩阵）：上下文词 embedding，训练后丢弃

这两个矩阵都在训练中被更新，但语义信息主要沉淀在 `W` 中。

**简化了的部分：**
- 没有实现层次 softmax（负采样在工程中已成为标准做法）
- 单线程训练（原始论文用了 24 线程并发更新共享参数）
- 没有实现词组检测（bigram scoring）

## 核心启示

1. **砍掉计算瓶颈，而不是砍掉模型能力。** 负采样把每次更新从 O(V) 降到 O(K)，这是几个数量级的加速，而不只是常数倍的优化。

2. **"简单"不等于"弱"。** 去掉非线性隐层、换掉精确 softmax，模型不仅没有变差，反而因为可以在更大语料上训练而质量更高。这是工程权衡中的重要教训。

3. **数据规模决定上限。** 词向量的"国王−男人+女人≈女王"这类令人叫绝的结果，来自在数十亿词的 Google News 语料上训练。小规模数据只能看到机制，大规模数据才能看到奇迹。

4. **表示学习的思想影响深远。** Word2Vec 让"预训练表示"这个概念深入人心，直接催生了后来的 GloVe、ELMo，乃至 BERT 和 GPT 时代的整个预训练范式。把语言中的语义结构压缩进低维连续向量，是现代 NLP 一切的基础。
